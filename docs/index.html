One player. Two matches.
A different story.

Marina Markova plays for VakifBank Istanbul against Scandicci twice. VakifBank wins both matches, but her numbers tell you more.

Her attack success goes from 43.2% to 55.6%: a higher share of her attacks scores a point in the second match.

Source: CEV matches 82223 and 82229. Full-match CSV copies are included in the project.

Attack success is the share of attack attempts that score a point. Attack efficiency also accounts for errors and blocked attacks. Reception error rate is the share of receptions recorded as errors; lower means fewer errors per reception.

Two performances illustrate a comparison, not a prediction or a claim about long-term improvement.

This program runs on your computer. You need a desktop or laptop, Node.js 20 or newer, and a modern browser. Install the Node.js LTS version if you do not already have it.

  1. Download the project ZIP and extract it, or clone the repository.
  2. Open a terminal in the extracted project folder and run npm start. No dependency installation is needed.
  3. Open http://127.0.0.1:3000 in your browser.
  4. Under CSV fallback, load samples/cev-82223-full-match.csv, then load samples/cev-82229-full-match.csv. Each imported match is saved automatically.
  5. Choose MARKOVA Marina in Compare a player across matches to see both performances together.
How do I open a terminal in the project folder?

Windows: open the extracted project folder in File Explorer, type cmd in its address bar, and press Enter.

macOS: open Terminal, type cd with a space, drag the extracted project folder into the Terminal window, then press Return.

Keep that terminal running while you use the app. If the address is already in use, open the address printed by npm start instead.

You can also paste a supported CEV report URL while the local server is running. CEV importing needs internet access; the included CSV samples work offline.

GitHub Pages hosts this introduction. Full CEV URL importing runs through the local Node.js server.
